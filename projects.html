CYBERSECURITY AUDIT

Breach Simulation: "The Neglected Closet"

Conducted a full-scope security audit simulating a legacy branch office network segment (172.27.71.0/24) containing unpatched, End-of-Life assets.

  • Discovery: Identified unencrypted Telnet (Port 23) using Wireshark and Nmap scripts.
  • Exploitation: Executed an automated dictionary attack, recovering admin credentials in under 5 minutes.
  • Remediation: Disabled legacy Telnet, rotated passwords to complex passphrases, and verified port closure via follow-up scans.
